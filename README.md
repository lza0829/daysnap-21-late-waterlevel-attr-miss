# 日镜账

中文名：**日镜账** · 前缀 `daysnap` · 端口 **6600 / 11600**

## 骨架

**日终余额抽取 → 周期快照落行 → 变动流水回放核对 → 断档/跳变检出 → 快照与回放差额清单**

皮：收单/结算账户的日终余额镜。去皮是 **周期快照事实 + 流水回放守恒 + 断档跳变检出**，不是银行核心 CRUD、不是日结封账锁定、不是双边齐账。

## 冒烟

```bash
docker compose up -d --build
# http://127.0.0.1:6600
# 台面 → 一键冒烟 → 周期快照有行 → 差额清单为空（或仅看最新回放批）
```

## 主链对象

| 对象 | 作用 |
| --- | --- |
| 账户册 | 参与日终抽取的账户 |
| 变动流水 | 按营业日增减额 |
| 周期快照 | 账户×营业日余额镜（版本链，当前镜主读） |
| 迟到处置单 | 每笔迟到流水一条，待处置→已纠偏，valid 证据 |
| 回放核对 | 前日当前镜+当日流水 vs 当日当前镜 |
| 差额清单 | 不一致行 |
| 断档/跳变 | 缺前日镜、偏离阈值 |
| 旁置簿 | 未入账载荷 |

## 流水迟到补抽（已落地 · 基镜+纠偏版本链）

全局唯一口径，禁止与「强制重抽盖写」混用：

- **基线行不可变**：首抽写 v1（版本号=1、是否当前=1），任何迟到都不 UPDATE 基线。
- **迟到只追加纠偏版本**：同日再抽插新版本行（v2、v3…）并翻转是否当前；`UNIQUE(账户键,营业日,版本号)` 保证链序，禁止无版本链直接盖写基行。
- **处置实体必在**：装载时账日已有当前镜即判迟到，与流水同事务写 `迟到处置单`（待处置）；抽取事务末尾结算为已纠偏，留前/后余额、纠偏批次、valid。禁止只触发重算无证据、禁止静默忽略。
- **失败闭**：装载/抽取均 `BEGIN IMMEDIATE` + `busy_timeout`；交叉冲突整体回滚并返回 409，不存在「流水已入而处置双无」。
- **只读接口**：`GET /api/迟到处置`（处置单，含 valid）、`GET /api/迟到处置/镜?视角=基线|当前|链`。
- **回看口径分叉可区分**：主读（`/api/快照` 默认当前镜）只有最新余额，读不回旧有效行；基线/链接口可沿 v1→vN 回看每笔迟到前旧余额。测试 `test_口径可区分_回看能力分叉` 显式锁定。
- 回放只读当前镜，迟到纠偏后回放守恒（零差额）。
- 注：版本链挂在快照**事实表**上、由迟到纠偏单驱动，不是 hourspan 式 SCD2 维表。
