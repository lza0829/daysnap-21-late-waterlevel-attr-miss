# 日镜账

中文名：**日镜账** · 前缀 `daysnap` · 端口 **6600 / 11600**

## 骨架

**日终余额抽取 → 周期快照落行 → 变动流水回放核对 → 断档/跳变检出 → 快照与回放差额清单**

皮：收单/结算账户的日终余额镜。去皮是 **周期快照事实 + 流水回放守恒 + 断档跳变检出**，不是银行核心 CRUD、不是日结封账锁定、不是双边齐账。

## 冒烟

```bash
docker compose up -d --build
# http://127.0.0.1:6600
```

## 主链对象

| 对象 | 作用 |
| --- | --- |
| 账户册 | 参与日终抽取的账户 |
| 变动流水 | 按营业日增减额 |
| 周期快照 | 账户×营业日余额镜（版本链，当前镜主读） |
| 迟到处置单 | 每笔迟到流水一条，待处置→已纠偏，valid 证据 |

| 断档/跳变 | 缺前日镜、偏离阈值 |
| 旁置簿 | 未入账载荷 |

## 流水迟到补抽（已落地 · 基镜+纠偏版本链）

全局唯一口径，禁止与「强制重抽盖写」混用：

- **基线行不可变**：首抽写 v1（版本号=1、是否当前=1），任何迟到都不 UPDATE 基线。
- **迟到只追加纠偏版本**：同日再抽插新版本行（v2、v3…）并翻转是否当前；`UNIQUE(账户键,营业日,版本号)` 保证链序，禁止无版本链直接盖写基行。
- **处置实体必在**：装载时账日已有当前镜即判迟到，与流水同事务写 `迟到处置单`（待处置）；抽取事务末尾结算为已纠偏，留前/后余额、纠偏批次、valid。禁止只触发重算无证据、禁止静默忽略。
- **失败闭**：装载/抽取均 `BEGIN IMMEDIATE` + `busy_timeout`；交叉冲突整体回滚并返回 409，不存在「流水已入而处置双无」。
- **只读接口**：`GET /api/迟到处置`（处置单，含 valid）、`GET /api/迟到处置/镜?视角=基线|当前|链`。
- **回看口径分叉可区分**：主读（`/api/快照` 默认当前镜）只有最新余额，读不回旧有效行；基线/链接口可沿 v1→vN 回看每笔迟到前旧余额。测试 `test_口径可区分_回看能力分叉` 显式锁定。
- 回放只读当前镜，迟到纠偏后回放守恒（零差额）。
- 注：版本链挂在快照**事实表**上、由迟到纠偏单驱动，不是 hourspan 式 SCD2 维表。

## 跨日水位账（已落地 · 甲口径「水位钉价值日」）

每笔「到达营业日 ≠ 价值日」的跨日迟到必须持水位账；本仓库选定并贯彻**甲口径**，禁止与「钉到达日」混用：

- **水位账必落**：装载同一事务为每笔跨日迟到写 `跨日水位账表`（水位号 / 流水号 / 价值日 / 到达营业日 / 归属日=价值日 / valid / 装载批次），流水行同时记 `到达日`、`水位号`。装载、封印、抽取、回放同票（水位账挂装载批与结算抽取批）。
- **归属日钉价值日**：净额只进**价值日**正式镜；重抽价值日追加纠偏版本（v2…）。到达日**永不**因该笔新增净额（禁止双日同加）。
- **封印闸 + 解封手续**：`营业日封印` 后该日正式镜冻结；动价值日正式镜（迟到装载 / 抽取）须持 `解封手续`，否则**整笔拒绝**（装载全批回滚，D1/D3 正式镜皆不变）。解封无手续一律拒绝。
- **失败闭**：伪造无水位号的跨日流水，抽取价值日或到达日都直接拒绝（禁止无水位双改）；迟到装载与封印抢锁时要么串行、要么整体回滚，绝不双日正式同加。
- **只读核证**：`GET /api/核证/跨日水位?键=`（水位号 / 归属日 / valid / 钉法 + 封印现场）、`GET /api/跨日水位`（按水位号/流水号/账户/归属日查）、`GET /api/封印`、`GET /api/封印/手续`；`/api/流水` 已带水位号/归属日/水位状态列。
- **台面入口**：`跨日水位核证` 页（水位账 + 封印/解封 + 手续流水），`日终抽取` 页可填写解封手续。
- 夹具：`跨日水位_基线.json`、`跨日水位_封印后迟到.json`、`跨日水位_解封后迟到.json`；测试 `test_跨日水位.py`、`test_跨日水位接口.py` 断言归属日与封印/双改失败闭。
